# FRESHEVAL: A Mobile Application for Real-Time Freshness Evaluation of Vegetables Using YOLOv8 and EfficientNetB7

**Thesis Project** | Built with **Flutter**, **Python**, **YOLOv8**, and **EfficientNetB7**  

FRESHEVAL is a mobile application that detects the freshness of vegetables in real time using computer vision and deep learning. Designed to reduce food waste and promote sustainable consumption, the app leverages object detection (YOLOv8) and image classification (EfficientNetB7) to evaluate vegetable quality with high accuracy.

---

## 📄 Abstract
This study presents **FRESHEVAL**, a mobile application for real-time freshness evaluation of eggplant, tomato, and potato. Using **YOLOv8** for object detection and **EfficientNetB7** for classification, the system analyzes visual features such as color, texture, and shape.  

YOLOv8 achieved a mean Average Precision (mAP@0.5) of **93.73%**, precision of **88.67%**, recall of **89.44%**, and F1-score of **89.05%**, with an inference speed of **8.1 ms/image**. EfficientNetB7 recorded an accuracy of **81.79%**, with macro and weighted F1-scores of **81.05%** and **81.52%**, respectively.  

Developed in **Flutter** with **TensorFlow Lite**, FRESHEVAL runs on-device for Android, ensuring fast and offline-capable processing. The application was evaluated via **ISO/IEC 25010** standards, scoring an average of **5.42** on a Likert scale, indicating strong functional suitability, performance efficiency, and reliability.

## 📱 Features
- **Real-Time Detection** – Capture or upload vegetable images for instant freshness evaluation.  
- **AI-Powered Analysis** – Uses YOLOv8 for object detection and EfficientNetB7 for freshness classification.  
- **Detailed Results** – Provides freshness status, shelf-life estimate, and recommendations.  
- **Scan History** – Saves past evaluations for easy reference.  
- **User-Friendly UI** – Built in Flutter for a smooth mobile experience.

## 🛠 Tech Stack

- **Backend:** Python
